# Inventory Management System

## Project Overview
The Inventory Management System is a web-based application designed to simplify inventory operations, product management, warehouse monitoring and sales tracking.

## Technologies Used
- Frontend: React, TypeScript
- Backend: Node.js, Express
- API Communication: tRPC
- Database: MySQL
- ORM: Drizzle ORM
- Styling: Tailwind CSS

## Main Features
- User Registration and Authentication
- Dashboard and Inventory Analytics
- Product Management
- Category Management
- Warehouse Monitoring
- POS and Invoice Generation
- Stock Movement Tracking
- Role-Based User Management
